The AI Career & Recruitment System (AI-CRS) is a role-based web application that supports employees, employers, and administrators through a controlled, modular workflow. Employees can create or upload multiple ATS-compliant CVs, explicitly trigger AI-based analysis per CV, and receive structured outputs including ATS scores, extracted skills, strengths, weaknesses, and improvement recommendations, with each analysis stored independently and associated with a specific CV version. Employers manage company entities, define job postings with structured requirements, and perform candidate discovery through indexed queries, filters, and AI-assisted ranking mechanisms that generate potential candidate lists based on CV–job matching scores. Administrators handle user lifecycle management, employer verification, system moderation, and role-based access control enforcement. The system is implemented using a modular monolithic architecture with a layered separation of concerns, where a React frontend communicates with a Node.js and Express backend structured around the MVC pattern, service layers, and repository abstractions. Data persistence is handled via a centralized MongoDB database optimized for document-based relationships, while AI functionality is isolated in a dedicated integration layer that communicates asynchronously with external AI APIs for natural language processing and semantic analysis tasks. AI-CRS is designed as a decision-support system, ensuring explainability, scalability, and maintainability without automating final hiring decisions.
